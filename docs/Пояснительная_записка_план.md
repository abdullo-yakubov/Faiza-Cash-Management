# План пояснительной записки

Тема: «Автоматизация регистрации и учёта кассовых операций в бухгалтерии ООО „Фаиза“».

Ориентировочный объём — 60–80 страниц без приложений `[УТОЧНИТЬ У НАУЧНОГО РУКОВОДИТЕЛЯ: требуемый объём, структура глав и оформление по методическим указаниям кафедры]`. ## Глава 4. Экономическая эффективность (8–10 стр.)

Все числовые значения — `[УТОЧНИТЬ]`; ниже — методика и формулы.

### 4.1. Затраты на разработку

`К_разр = З_ср × Т_разр × (1 + k_отч) + С_маш + С_проч`, где

- `З_ср` — среднемесячная заработная плата программиста в РТ `[УТОЧНИТЬ: источник — данные Агентства по статистике при Президенте РТ или вакансии]`;
- `Т_разр` — трудоёмкость в месяцах (по журналу коммитов и плану этапов) `[УТОЧНИТЬ]`;
- `k_отч` — ставка отчислений (социальный налог) `[УТОЧНИТЬ: действующая ставка по Налоговому кодексу РТ]`;
- `С_маш` — стоимость машинного времени: `С_маш = Ч_маш × Ц_ч` (часы работы ПК × стоимость часа, включая электроэнергию и амортизацию) `[УТОЧНИТЬ]`;
- `С_проч` — прочие расходы (доменное имя, сертификат — бесплатный Let's Encrypt через Caddy) `[УТОЧНИТЬ]`.

### 4.2. Затраты на внедрение и эксплуатацию

`К_внедр = С_сервер + С_обуч + С_перенос`; `Э_год = С_хостинг + С_адм × t_адм + С_эл`

- сервер или облачная аренда, обучение пользователей (часы × ставка), перенос начальных остатков и справочников; годовая эксплуатация — хостинг, время администратора, электроэнергия `[УТОЧНИТЬ У ЗАКАЗЧИКА]`.
- ПО — свободное; проверить условия лицензии QuestPDF `[УТОЧНИТЬ]`.

### 4.3. Экономия от автоматизации

Экономия рабочего времени по каждой операции i:

`ΔT_i = (t_руч,i − t_авт,i) × N_i`, годовая экономия `Э_вр = Σ ΔT_i × С_час`,

где `t_руч,i`, `t_авт,i` — время операции вручную и в системе (хронометраж до и после) `[УТОЧНИТЬ У ЗАКАЗЧИКА]`, `N_i` — число операций в год `[УТОЧНИТЬ]`, `С_час` — стоимость часа работы бухгалтера/кассира с отчислениями `[УТОЧНИТЬ]`.

Операции для хронометража: оформление ПКО/РКО; закрытие дня (смены) со сверкой; подготовка кассовой книги за месяц; отчёт по филиалам; авансовый отчёт; инвентаризация; поиск документа для проверки.

Снижение потерь от ошибок и недостач: `Э_ош = (П_до − П_после)` — средние годовые потери до и после внедрения `[УТОЧНИТЬ У ЗАКАЗЧИКА; при отсутствии данных — описать качественно, без выдуманных цифр]`.

Итоговая годовая экономия: `Э = Э_вр + Э_ош − Э_год`.

### 4.4. Показатели эффективности

- Срок окупаемости: `Т_ок = (К_разр + К_внедр) / Э` (лет).
- Коэффициент эффективности: `Е = Э / (К_разр + К_внедр)`; сравнить с нормативным `Е_н` `[УТОЧНИТЬ У НАУЧНОГО РУКОВОДИТЕЛЯ: принятое значение Е_н]`.
- При желании — чистый дисконтированный доход: `ЧДД = Σ_t Э_t / (1 + r)^t − К`, ставка `r` — ставка рефинансирования НБТ `[УТОЧНИТЬ: значение на дату расчёта]`.

### 4.5. Неэкономические эффекты
- Неизменяемость документов и аудита; разделение обязанностей; оперативная видимость остатков по филиалам; контроль подотчётных сумм; сохранность данных (шифрованные копии с проверкой восстановления).

Таблицы главы: исходные данные; смета разработки; хронометраж «до/после»; расчёт экономии; итоговые показатели.
