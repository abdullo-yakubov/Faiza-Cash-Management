# Рекомендации для диплома

1. Чётко отделить доказанные возможности текущей системы от предложенной модели смен.
2. В главе предметной области показать реальный внешний процесс компании, но не утверждать внутренние регламенты без документов заказчика.
3. Для демонстрации использовать только подтверждённые сценарии: вход, касса, черновик, проведение, сторно, отчёт и аудит.
4. Отдельно описать ограничения: смены, hard limit, филиалы, заказы и live production TLS требуют согласования/отдельной проверки.
5. Сослаться на публичные страницы компании и на конкретные пути/строки репозитория, перечисленные в GAP-анализе.
