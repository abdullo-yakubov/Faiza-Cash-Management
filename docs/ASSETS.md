# Графические ресурсы Faiza Gold

Все перечисленные иллюстрации созданы специально для этого проекта в SVG. Внешние фотографии, логотипы, шрифтовые CDN и растровые изображения не используются.

| Файл | Содержание | Источник и лицензия |
|---|---|---|
| `frontend/src/assets/hero/login-hero.svg` | Абстрактная иллюстрация карточки финансовой операции для входа | Создана для проекта; исходный SVG проекта |
| `frontend/src/assets/illustrations/empty-state.svg` | Иллюстрация пустого состояния | Создана для проекта; исходный SVG проекта |
| `frontend/src/assets/icons/faiza-gold.svg` | Фирменный знак в компоненте логотипа | Создан для проекта; исходный SVG проекта |
| `frontend/public/faiza-gold.svg` | Знак Faiza Gold | Создан для проекта; исходный SVG проекта |
| `frontend/public/favicon.svg` | Favicon | Создан для проекта; исходный SVG проекта |

Шрифт использует системный стек `Inter`, `Segoe UI`, `Arial` с поддержкой кириллицы. Веб-шрифт не скачивается извне; локальный webfont в репозитории пока не поставляется.
