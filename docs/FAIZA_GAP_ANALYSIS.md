# Анализ разрывов

## Критические разрывы

- В модели нет `Branch`, поэтому изоляция и отчётность по филиалу пока выражаются только через кассу.
- Нет отдельного агрегата межкассового перемещения; две независимые операции могли бы исказить доход.

## Функциональные разрывы

- Операция может иметь контрагента, но не имеет основания платежа, внешнего заказа и распределения по частичной оплате.
- Отчёты есть по кассе, но не консолидируются по филиалу.

## Что уже закрыто

Авторизация, доступ к кассам, смены, лимиты, идемпотентность, финансовый ledger, сторно, PDF/CSV, аудит и UI не следует переписывать. Это подтверждено локальной сборкой и тестами 2026-11-14.
